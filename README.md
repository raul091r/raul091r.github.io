# Raul's portfolio

A plain HTML, CSS, and JavaScript portfolio that can be hosted on GitHub Pages.

## Preview locally

Open `index.html` in a browser, or serve the repository with any static file
server. No build step or package installation is required.

## Publish with GitHub Pages

1. Push this repository to GitHub.
2. In the repository settings, open **Pages**.
3. Choose the branch and `/ (root)` as the publishing source.
4. Save. GitHub Pages will publish the site from the repository root.

## Personalize the placeholders

- The home hero and page backdrop use original CSS/SVG sunset art, palms, and
  subtle motion on unbranded sports-car silhouettes.
- Replace the six SVG files in `assets/images/projects/` with your own project
  screenshots or photos. Keep the filenames or update the image paths and alt
  text in `pages/projects.html`.
- Search the pages for `[PLACEHOLDER: ...]` and replace each note with your
  details. The contact email is set in the contact page and shared footer.
- Add any remaining activities, skills, and project notes in
  `pages/about.html` and `pages/projects.html`.

All pages share the same navigation and footer. The mobile menu and project
image viewer work with plain JavaScript and do not require a framework.
